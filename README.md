# Shinland

> My digital home — a personal portfolio where my story, projects, and growth as a developer come together.

Shinland is my personal developer portfolio built with modern frontend technologies.  
It showcases my work, skills, experiments, and the journey behind becoming a developer.

The goal of this project is to create a clean, responsive, and meaningful digital space that represents both my technical abilities and my approach to building user experiences.

## ✨ Features

- Personal introduction and developer journey
- About section
- Skills showcase
- Project presentation
- Responsive layout for desktop and mobile
- Modern UI interactions and animations
- Contact and social links

## 🛠️ Tech Stack

- **React** — UI development
- **TypeScript** — Type-safe JavaScript
- **Vite** — Fast development environment and build tooling
- **Tailwind CSS** — Styling and responsive design
- **Lucide React** — Interface icons
- **ESLint** — Code quality and consistency

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/Shinland.git
```

Navigate into the project:

```bash
cd Shinland
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
